# A-B-Testing-Analytics
This project analyzes the results of an A/B test for a website landing page to determine whether a new landing page improves user conversion compared with the existing landing page.

Business Problem
A company currently uses an old landing page on its website.

The marketing/product team has developed a new landing page and wants to determine whether it performs better.

The experiment divides users into two groups:

Control group → users exposed to the old landing page
Treatment group → users exposed to the new landing page

The primary business objective is to determine whether the new page generates a higher conversion rate.
